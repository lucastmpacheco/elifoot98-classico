# Elifoot 98 — versão clássica para Windows 10 e 11

O Elifoot 98 de André Elias e Ricardo Correia (1998), igual ao original, refeito para rodar nativamente nos Windows modernos (32 e 64 bits). Inclui o jogo e o Editor de Equipas.

## Baixar

Na aba **Releases**, baixe `Elifoot98-classico-instalador.exe` e execute.

- Na primeira vez o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações** → **Executar assim mesmo** (o instalador não tem assinatura digital paga).
- Instale numa pasta onde o seu usuário possa gravar (a sugerida é `C:\Jogos\Elifoot 98`), não em "Arquivos de Programas".
- O jogo vem **não registrado**, como o original. Detalhes em `LEIA-ME.txt`.

## Conferir o arquivo

SHA256 do instalador: veja `SHA256.txt` na release.
